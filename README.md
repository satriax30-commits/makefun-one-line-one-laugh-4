A deterministic Node 22 program (stdlib only) that writes one original funny line to `/output/entry.txt` for make.fun's "One Line, One Laugh" bounty. The line:

> I asked my smart speaker for relaxing music. It played my bank balance notifications.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` by default. Pass an output directory to test locally:

```sh
node main.ts /tmp/out
```

The program self-checks the gate before writing (1–200 characters, one line, not only whitespace) and verifies the file by reading it back.

## Why this line

Four candidates were drafted; this one won because the twist lands on the last two words and is concrete — the one sound nobody relaxes to is your own bank balance. Every word earns its place, it reads clearly the first time, and it is not a joke already making the rounds.

Rejected: a phone-autocorrect-to-therapy line (the joke explains itself), a standing-desk line (reversal good, punch too gentle), a smartwatch-congratulates-me-for-standing line (stock "snacks" punch), and a smart-fridge line (two jokes fighting in one line; setup longer than the punch).
